# 04 — 前端：路由、API 客户端与目录结构

**What to build:** 前端当前只有一个 `App.tsx` 调用健康检查，没有路由、没有请求层、没有组件目录约定。这张工单把这些搭出来，让后续每个业务页面都只需关心自己的逻辑。

铺垫工单，本身没有业务功能，但完成后应能在浏览器里通过 URL 在两个页面（现有的健康检查诊断页 + 一个空的知识库页占位）之间导航。
