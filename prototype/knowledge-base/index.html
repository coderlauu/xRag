原型演示控制台 切换状态以核对文案与按钮规则 展开 ▲
这一栏是脚手架，不是产品的一部分——真实系统里这些状态由后端数据决定。它存在的唯一理由是让评审者在 React 代码写出来之前就能核对 ui-spec.md 里那些光读文档很难判断的东西：四种状态的按钮文案是否合理、RUNNING 时该灰的是否都灰了、 SKIPPED 的措辞会不会让人误以为出错、四种错误提示是否真的告诉了用户下一步做什么。

「开始处理」可以直接点，会依次走完五个 phase 再进 SUCCESS，用来核对 §4 的阶段文案与 §3 的禁用规则。 创建/编辑知识库这个表单点了只会提示"规格未定"——ui-spec.md 目前没有规定它的字段与校验， 原型不替规格做决定。「编辑文档」与「添加链接」原本也在这一列，`2026-07-26` 补了 ui-spec §11 / §12 之后已经实现出来：前者可核对字段、三条校验、以及改了分块参数后那个"要不要立即重新处理"的后续弹层； 后者可核对直链提示、定时同步开关的显隐、以及最短间隔那条与钱挂钩的校验。
