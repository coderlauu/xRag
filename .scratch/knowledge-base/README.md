# 工单：AI 知识库建设模块

本目录是 [分角色任务书](../../docs/exec-plans/active/2026-07-25-knowledge-base-implementation-lanes.md) 的执行视角拆解：19 张垂直切片工单，按依赖顺序编号（阻塞者在前）。

每张工单是一条**跨层的完整可验证路径**，不是某一层的横向切片。例外是 `01`~`04`——它们是前置铺垫（"先让改动变容易，再做容易的改动"），本身不产生用户可见行为。

**推进方式**：做**前沿**（frontier）——任何"Blocked by 全部已完成"的工单都可以开始，不必严格按编号串行。
